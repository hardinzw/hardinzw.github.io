Projects

Short Stack OBX

Short Stack OBX is the website for an Outer Banks vacation rental, where guests can browse photos, see open weeks and book directly instead of going through Vrbo or Houfy. It's a hand-written HTML/CSS/JavaScript page with no framework, served by a Cloudflare Worker that also runs a small booking API backed by a Cloudflare D1 (SQLite) database. Payments go through Stripe Checkout, so card details never touch the site, and Stripe webhooks with verified signatures move each booking from hold to paid. To prevent double bookings, the Worker checks direct bookings and the live Vrbo and Houfy calendars, holds the week while the guest pays, and refunds automatically if the week was taken in the meantime. It also publishes its own iCal feed so the listing platforms block booked weeks too, and GitHub Actions deploys the site and API together on every push.

Dynasty Data
